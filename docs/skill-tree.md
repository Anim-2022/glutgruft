- Статусы `brand, stun, sproede, dodge, stark, wall, gift`, функции `ignite`, `gain`, `addAff`, массив `traps` — основа большинства новых узлов.

- Фиксированные 3 навыка → новые навыки (T3) занимают слоты 4–6; хоткеи `1–3` → `1–6`, HUD шире.

## 3. Два уровня

**а) Лагерь.** Души открывают узлы, то есть добавляют их в пул забега. Никаких статов от меты.
- Бесплатно открыты (без душ) у каждой ветки: **T1, T2a, T4a, T4b**.
- За души открываются только **T2b, T3 (новый навык), T5 (ключевой)**.
- Платный узел можно открыть, только если открыт его родитель.

**б) Забег.** Очко дерева на каждом 3-м уровне (3, 6, 9, …), на остальных — Gabe (раздел 5). ~9 очков к 28-му уровню. Выбор — любой доступный узел: открыт в лагере и выполнено условие. Очки можно отложить («später»).

**Restpunkt.** Если доступных узлов нет, очко сразу превращается в дополнительный выбор Gabe. Отложенные очки, которые потратить некуда, тоже превращаются в Gabe — при следующем level-up или открытии дерева.

Хватает ли узлов:
- neu: T1 + T2a + одна из T4 = 3 узла на ветку × 3 = **9** ≈ 9 → все очки тратятся, Restpunkt почти не нужен.
- max: 6 узлов на ветку × 3 = **18** > 9 → нужен выбор, полностью закрыть можно ~1,5 ветки.
- Шаг 2a (только T1, T4a/b): 2 узла на ветку × 3 = 6 → ~3 очка в Restpunkt.

 ├─ T2b пассив                           ← T1                      40

T4a | T4b  III-A / III-B (взаимоискл.)   ← T1, ≥2 очка в ветке     бесплатно

- В шаге 2a T2/T3 ещё нет, поэтому временно T4 ← T1 без порога очков.
- T2a бесплатны, но это новый контент: появляется в 2b–2d.

## 5. Дерево и Gaben

**Вариант A — чередование (выбран).** Каждый 3-й уровень → очко дерева, остальные → Gabe как сейчас, но без карт рангов. (Первоначально было «чётный/нечётный»; изменено после замеров 2a, см. раздел 11.) Weisheit влияет только на Gaben. Restpunkt превращает лишние очки в Gaben. Плюсы: сохраняются случайность и синергии, бюджет силы близок к текущему, минимум правок в `offerPerks`. Минус: на max даров меньше → синергии реже.

**Вариант B — замена (отклонён).** Gaben становятся 4-й общей веткой «Allgemein», очко на каждом уровне. Полный контроль билда, но пропадает вариативность забегов, 27 даров пересобирать.

Отклонено также «дополнение» (очко + Gabe на каждом уровне) — инфляция силы.

## 7. Данные (набросок)

- `content.ts`: `TREE: Record<ClassId, BranchDef[]>`, узел `{ id, name, desc, parent, minPts, cost, key?, excl?, skill? }`.
- `Meta.tree: Record<ClassId, string[]>` — открытые платные узлы; бесплатные считаются открытыми всегда.
- `Player.tree: string[]`, `Player.pts: number`.
- Миграция сейва меты: нет `tree` → пустые списки.
- Миграция сохранённого забега: нет `p.tree` → восстановить из рангов (`skillLvl ≥ 1` → T1; `skillLvl = 2` → T4a/T4b по `skillMod`), чтобы ранг нельзя было взять повторно; `pts = 0`.
- Эффекты пассивов — через `aff`/флаги в существующих местах.

## 8. Бот и `npm run balance`

Переменная `BUILD`:
- `heur` (по умолчанию): ветка-фокус = `seed % 3` (равномерно). Порядок: T1 → T3 → T4 (a/b по чётности seed) → T5 → T2a → T2b, затем следующая ветка так же.
- `random`: равновероятно из доступных узлов.
- `feuer|eis|arkan|schild|klinge|schlachtruf|scharf|fallen|pirscher`: принудительная ветка-фокус для всех сидов (замер разброса веток, с шагов 2b–2d).

Мета: `neu` = только бесплатные узлы (T1, T2a, T4a, T4b) + `UPGRADES` на 0; `max` = все узлы открыты + `UPGRADES` на максимум (как в v4). При необходимости `mittel`.

Боту нужны правила для каждого нового навыка и ключевого узла (Kryomant — бить оглушённых и боссов; Anlegen — не двигаться, если враг в радиусе; Blutzorn — не платить HP ниже 40 %). Без этого ветка выглядит слабой из-за бота, а не дизайна.

Отчёт balance дополнить: победы и медиана этажа по класс × мета (× ветка-фокус); души/забег; среднее число Gaben и рангов за забег и уровень взятия рангов; доля очков в Restpunkt; частота выбора узлов в `random`.

## 9. Риски и KPI

Риски:
- Свободный ход (Zeitriss, Klingenrausch) → бесконечные комбо. Жёсткая перезарядка, тест «подряд не больше 1 хода без хода врагов».
- Blutzorn + вампиризм/Blutwirbel → вечный ресурс. Ограничить лечение от навыков при Blutzorn.
- Стан-лок (Frostnova + Eislanze + Fangnetz + Schildwurf + Bärenfalle): боссы уже 1 ход; обычным мобам — иммунитет 1 ход после стана, вводится вместе с новыми источниками стана.
- Kryomant / Minenfeld ломают ресурс-экономику → метрика «ресурс = 0 больше X % ходов»; против боссов у Kryomant отдельное правило (+2 Mana за удар по боссу).
- Новые навыки дают Krieger дальний бой → меняются смерти от `schuetze`.
- Вариант A: даров меньше → синергии реже.
- Смещение бота: KPI веток валидны только при равных правилах бота.
- 2160 душ на всё — темп прогрессии калибровать по «души/забег».

KPI (N = 80 сидов на ячейку):
1. Победы класс × мета: **neu 8–20/80, max 28–46/80**.
2. Разброс веток: в каждой ячейке класс × мета (`BUILD=<ветка>`) max(победы)/min(победы) ≤ 2; при min < 10 сравнивать медиану этажа (разница ≤ 3).
3. Разброс классов на max: ≤ 1,5×.
4. `random` ≥ 60 % побед `heur` — в дереве нет узлов-ловушек.
5. Прогресс меты: max ≥ 2× neu по победам.
6. Ключевые узлы: билд с T5 не хуже того же билда без T5 больше чем на 25 %.
7. Стабильность: 0 зависаний в 14000 действий, `npm test` зелёный.

## 11. Решения по замерам 2a

- В v4 бот никогда не брал карты рангов (выбирал первую карту, ранги лежали в конце) → эталон v4 = «все уровни в Gaben».
- Боту добавлены правила для Falle, Ausweichrolle, Kriegsschrei (инструмент замера, не баланс).
- Чередование «чётный/нечётный» давало вдвое меньше Gaben: Magier neu, Waldläufer neu/max вне коридора (3 набора сидов).
- Единственная правка дизайна: очко дерева на каждом 3-м уровне (`TREE_EVERY = 3`), Restpunkt без изменений. Сила рангов, цены и Gaben не менялись.
- Замер: `N=80 SEEDS=0|1|2 npm run balance` (SEEDS=k сдвигает сиды на k·1000003).
- Итог (N=80 × 3 набора, heur): каждый 3-й уровень — neu 17,3 / 8,0 / 0,7, max 40,0 / 35,7 / 23,7 (Krieger / Magier / Waldläufer). Waldläufer neu и max всё ещё вне коридора → стоп, эталон v5-base не утверждён. Сырые данные: `tests/balance-2a/`.
