# Glutgruft

Rundenbasiertes Pixel-Roguelike für den Browser. Keine Installation, kein Konto, Spielstand im Browser.

## Entwicklung

```bash
npm install
npm run dev      # lokaler Server
npm test         # Logiktests
npm run build    # Ausgabe in dist/
```

## Deployment (Cloudflare Pages)

Build-Befehl `npm run build`, Ausgabeverzeichnis `dist`.

## Steuerung

Pfeile/WASD bewegen und angreifen · Leertaste warten · 1–3 Fähigkeiten · F Fernangriff · Q Heiltrank · E Treppe
